# Noct Themes Gallery

## About the Noct Themes Collection
`Noct` presents a wide variety of themes to choose from and hopefully there is something for everyone who may use it.

In the screenshots below, `Noct's` default long directory listing, (`nt -l`), is displaying my humble home directory, and together, they serve as the motif for presenting the `Noct Themes Collection`. Most screenshots are taken against a black background with very little transparency, but many of the themes do very well on other backgrounds with or without transparency.


You are encouraged to experiment with different themes on different backgrounds.

In fact, `Noct's Daylight`-series themes, which can be seen further down on white background, are actually all displayed *twice* in this gallery; the second time on a dark, lightly transparent, background to display their versatility. 

These `Daylight`-theme screenshots, taken on a dark background, are mixed with the regular `Daylight`-themes on white background.  (The text clearly shows which are which.)

# How To Work With Themes

## Using a Theme With Noct (And Generating noct.toml)
To make a theme work with `Noct` you must first place the themes files in the correct directory, and then add a string to your **config** file, `noct.toml`, specifying the theme you wish to apply. 

This is how you do it:

1. Place the downloaded theme files in `~/.config/noct/themes/`, so that the files are sitting directly inside that directory. 

2. Add to the very top of your `noct.toml`, the line `theme = "theme_name"`, where *theme_name* is the name of the theme file itself, excluding the file extension. So, for example, if you want to apply `Ash Violet`, first make sure that the file is in the `themes/` directory, and then add the line `theme = "ash_violet"` at the top of `noct.toml`. If you do NOT have the `noct.toml` file, see next step.

3. At the command-line, run `nt --generate-config`. Then cd to `~/.config/noct/`. Check the contents of that directory. There should now be a file named `noct.toml.generated`. Remove the extension **.generated** by renaming the file to `noct.toml`. Now open the newly renamed `noct.toml` with your favourite editor and add the mentioned line at the top of the file.

    NOTE: It must be entered ***before*** the `[display]` section begins!

4. Make sure that you save the changes to `noct.toml` so that the changes definitely apply. 

5. Now run `noct` as you normally would from the command-line and the new theme colours will shine in your terminal. 

NOTE: If you already have a `noct.toml`, beware of that running `nt --generate-config` will not touch the existing config file but will create a second file called `noct.toml.generated`. To use the new one, you must first remove your old one and rename the newly generated file to `noct.toml` and then you need to make the settings you had in the old file anew in your generated file.

## How To Create Your Own Theme

The easiest way is also the recommended, and that is to simply copy your favourite theme and name it whatever you want your new theme to be called. If you want the theme to be called **Hello World**, then you name your new file `Hello_World.toml`. 

**Beware that case sensitivity matters.** 

Once you have the file prepared, open it with your favourite editor, and the fun can begin!

The first thing you do inside the theme file is to enter the name of your theme. You do this somewhere near the top of the file. It looks like this:

`name = "Hello_World"`

Now we get to the actual colour tags. You have nine (9) **sections** in the theme file. The **sections** are (in order):

```
[file_type]
[permissions]
[columns]
[names]
[classification]
[tags]
[report]
[header]
[summary]
```



These **sections** are simply a way of categorizing the different tags rather than just lining them up without any order whatsoever. The **sections** will help you keep thigns organized.

Under each section you find a list of **tags**. A **Tag** consists of a *name*, which is descriptive in terms of what is to be coloured, and a *hexadecimal value* in the form `#RRGGBB`. 

Unless you are an android or a computer, you will need some sort of help with generating these hexadecimal colour codes. It's true, that, after a while, you will learn a bunch of hexadecimal values by heart. But if you are new to this, it is recommended to use a colour calculator that generates the hexadecimal values for you as you yourself decide the colour by manipulating a colour control.

I personally use W3 School's calculator, which can be found at the following URL:

https://www.w3schools.com/colors/colors_hexadecimal.asp

Now that you know how to generate the hexadecimal values for the colours you wish to base your theme on, it is time to start using these values.

## Applying the Hexadecimal Colour Values

You are probably right now staring at the first **section** called `[file_type]`. It deals with the colours for the most ordinary file types such as **files**, **directories**, **symlinks**, and **special** file types. You are now familiar with what this section looks like, but here is a reminder on the way:


```
[file_type]
file = "#d2d7e1"
directory = "#9c6bdb"
symlink = "#9c6bdb"
special = "#8a8f99"
```


So if you wish to use a sharp green in your theme for `file` you generate your value and modify the appropriate entry in the section:

`file = "#40ca40"` # green

The entry on the right-hand side that says **# green** is a comment. You can use them to remember what colours the codes represent. This is very useful when you are working with fifteen, twenty or more colours.

Then you feel like using a heavy violet for **directories**:

`directory = "#393165"` # heavy violet

And for **symlinks** you have chosen a sort of cyan:

`symlink = "#18c9cb"` # bright cyan

## Leaving Out Entries
Now you have only one tag left in this section. If you can't come up with colours for all the tags, which can be tedious work, you can comment them out (but hey - you **are** here to create a theme, right?)

To comment out an entry, put a hashtag (#) in front of the entry you wish to omit. When you omit entries, `Noct's` fallback will kick in and apply default colours from its built-in default theme. 

NOTE: Omitting entries by commenting them out may not harmonize with your chosen colours. That is why we recommend you NOT to omit any entries. It's better to enter the same colour for multiple entries, than to omit entries and use `Noct's` fallback system. But who knows, you may be in luck and it ***could*** actually harmonize but you shouldn't bet your last obol on it :)
